Click any duty cell to pick a valid code from the dropdown. Red cells are codes not in the time-slot table ("O" is accepted as OFF, "L" is accepted as G, "M12" is accepted as M). Pink cells mark a duplicate employee code. A default 0000 / HCM row is always added at the top. Use Convert to Time Slot ID to map every cell to its numeric ID (e.g. G → 101) and fill empty cells with G (101).
